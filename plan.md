## Palette App
- Overall, improve the palette builder with features that enhance the user experience.
- Add a button to transform the current palette into specific themes (e.g., pastel, neon, muted).
- Add support for common harmonic color schemes, such as complementary, analogous, triadic, and tetradic.

## Mood Board App
- Add a feature (e.g., a "Dynamic" mode button) to enable dragging images freely around a canvas.
- Add support for sticky notes.
- Allow extracting color swatches directly from the currently selected image.
